# 💼 Balaram Gochhayat - Personal Portfolio Website
![image](https://github.com/user-attachments/assets/2be2ca98-c33f-4eba-8956-455f8dd54fd6)

Welcome to my personal portfolio repository!  
This responsive website showcases my skills, certifications, projects, and experience as a budding software developer.

🔗 **Live Website**: [balaramportfolio.netlify.app](https://balaramportfolio.netlify.app)

## ✨ Highlights

- Interactive landing page with animated intro
- Sectioned layout: About, Skills, Education, Experience, Projects, Certificates, Hobbies, and Contact
- Downloadable resume and social media links
- Scroll reveal and typewriter animations
- Google Sheets integration for contact form
- Mobile responsive design
- Smooth transitions and modern UI

## 🛠️ Tech Stack

| Purpose       | Technology                          |
|---------------|--------------------------------------|
| Markup        | HTML5                               |
| Styling       | CSS3, Animations                    |
| Scripting     | JavaScript                          |
| Frameworks    | ScrollReveal, Typed.js              |
| Hosting       | Netlify                             |
| Integrations  | Google Apps Script (contact form)   |
